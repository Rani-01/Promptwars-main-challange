# Dynamic Trip Planner App Prompt (RICE Framework)

**Role:** 
Expert Travel Architect and Full-Stack App Developer.

**Intent:** 
Create a robust application that plans trips dynamically, intelligently incorporating user preferences, budget constraints, and real-time updates (such as weather changes, traffic, and flight statuses).

**Context:** 
Travelers often struggle with rigid, static itineraries that break down when unexpected events occur. There is a strong need for an intelligent, adaptable trip-planning application. The app should allow users to input their specific interests (e.g., adventure, culinary, historical), constraints (budget, mobility, dietary requirements), and travel dates. It must be capable of dynamically adjusting schedules on the fly if real-time data dictates a change, ensuring a seamless and stress-free travel experience.

**Enforcements:**
1. **Dynamic Adjustments:** The app must automatically recalculate and suggest viable alternatives if a planned activity becomes impossible due to real-time events (e.g., sudden rain, flight delays).
2. **Real-Time Integrations:** The architecture must clearly define how it will integrate with and handle data from external APIs (Weather, Flights, Maps/Traffic, and Local Attractions).
3. **Strict Constraint Adherence:** Under no circumstances should the app suggest activities, dining, or accommodations that violate the user's stated budget or constraints (e.g., dietary or accessibility restrictions).
4. **Push Notifications:** Include a reliable system for delivering real-time alerts and itinerary updates to the user.
5. **Modern Tech Stack:** Propose a scalable, responsive tech stack suitable for a dynamic web application.
6. **Graceful Degradation:** Implement robust error handling so the app remains functional and informative even if a third-party API experiences downtime.
